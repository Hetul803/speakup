# SpeakUp Submission Assets

Use these files in the Kaggle media gallery and video upload flow:

- `speakup_thumbnail.png`: 1280x720 YouTube/Kaggle cover image.
- `speakup_icon.png`: 512x512 app icon.
- `speakup_thumbnail.svg` and `speakup_icon.svg`: editable source files.

The app manifest uses matching icons from `frontend/public/`.
